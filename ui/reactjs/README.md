# Healthcare RAG Copilot

A modern **React.js + TypeScript frontend application** for interacting with a Healthcare Retrieval-Augmented Generation (RAG) API.

The application provides a user-friendly interface for submitting healthcare knowledge questions to a FastAPI RAG backend and visualizing validated answers, retrieval metadata, source documents, and multi-agent workflow outputs.

---

## Overview

The **Healthcare RAG Copilot** is designed to provide healthcare knowledge retrieval through a Retrieval-Augmented Generation workflow.

Users can submit healthcare or clinical operations questions and optionally filter the knowledge retrieval process by:

* Document type
* Department
* Document name
* Number of retrieved documents (`Top K`)
* Source inclusion

The frontend communicates with the following FastAPI endpoint:

```text
POST http://127.0.0.1:8000/rag/ask
```

The RAG API response is presented through a structured dashboard containing:

* Validated RAG answer
* Validation status
* Confidence score
* Retrieved document count
* Execution time
* Validation notes
* Source documents
* Relevance scores
* Document metadata
* Multi-agent outputs

### `rag.ts`

Contains TypeScript interfaces for the RAG API.

The main request interface is:

```typescript
export interface RAGRequest {
  question: string;
  top_k: number;
  document_types: string[];
  departments: string[];
  document_names: string[];
  include_sources: boolean;
  conversation_history: ConversationMessage[];
```

The main response interface is:

```typescript
export interface RAGResponse {

  question: string;

  sources: Source[];
  agent_outputs: AgentOutput[];
  session_id: string | null;
  execution_time_seconds: number;
  message: string;
}
```

## CORS Configuration

If the frontend displays the following error:

```text
Unable to connect to http://127.0.0.1:8000/rag/ask.
Verify FastAPI and CORS configuration.
```

Ensure CORS is configured in FastAPI.

Example:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",
        "http://127.0.0.1:5173"
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

For local development only, all origins can temporarily be allowed:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

Use restricted origins in production environments.

## Troubleshooting

### Unable to Connect to FastAPI

Verify the backend:

```bash
uvicorn main:app --reload --port 8000
```

Verify the API endpoint:

```text
http://127.0.0.1:8000/rag/ask
```

Verify `.env`:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

Restart the Vite development server after changing environment variables.

```bash
npm run dev
```

---

### CORS Error

Configure FastAPI `CORSMiddleware`.

Ensure the frontend origin is allowed:

```text
http://localhost:5173
```

or:

```text
http://127.0.0.1:5173
```

---

### Empty Source Documents

Verify:

```text
include_sources = true
```

Also verify that the backend returns:

```json
"sources": []
```

with populated source objects when matching documents are retrieved.

---

### Incorrect Percentage Values

The frontend assumes confidence and relevance scores are decimal values.

Correct:

```json
{
  "confidence_score": 0.95
}
```

Displayed as:

```text
95.0%
```

Incorrect:

```json
{
  "confidence_score": 95
}
```

This would display:

```text
9500.0%
```

---

### Agent Outputs Are Not Displayed

Verify the API returns:

```json
{
  "agent_outputs": [
    {
      "agent_name": "Validation Agent",
      "output": "Agent response"
    }
  ]
}
```

The application displays the agent output only when the array contains one or more items.
